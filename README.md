# M42 AI Assistant – Feedback

Hier kannst du Fehler melden, Verbesserungen vorschlagen und den Fortschritt deiner Meldungen verfolgen.

**Einrichtung läuft:** Meldungen können bereits erstellt werden. Die automatische Übernahme und Status-Synchronisierung werden noch aktiviert und geprüft.

**[Neue Meldung erstellen](https://github.com/kenhaesler/m42-ai-assistant-feedback/issues/new/choose)** · **[Meldungen ansehen](https://github.com/kenhaesler/m42-ai-assistant-feedback/issues)**

Du brauchst ein GitHub-Konto. Dieses Repository enthält die öffentlichen Formulare und Informationen zum Feedback-Kanal. Der Anwendungscode ist privat.

## Was passiert mit meiner Meldung?

Das Projektteam übernimmt die Meldung in seine interne Bearbeitung. Dein öffentliches Issue bleibt bestehen. Antworten und Status-Updates erscheinen hier; mit **Subscribe** im Issue kannst du GitHub-Benachrichtigungen abonnieren.

| Status | Bedeutung |
| --- | --- |
| Eingegangen | Die Meldung ist beim Team angekommen. |
| Zugewiesen | Jemand hat die Bearbeitung übernommen. |
| In Bearbeitung | Das Team arbeitet daran. |
| In Review | Die Lösung wird geprüft. |
| Geschlossen | Die Bearbeitung ist abgeschlossen. |
| Nicht geplant | Derzeit ist keine Umsetzung vorgesehen. |

Die Übernahme wird ungefähr alle fünf Minuten geprüft. GitHub kann geplante Läufe verzögern. Die Statuspflege erfolgt durch das Projektteam; ergänze weitere Informationen oder Wiedereröffnungswünsche als Kommentar.

## Bitte nur öffentliche Informationen

**Alle Issues und Kommentare sind weltweit sichtbar.** Keine Personendaten, echten Ticketinhalte, Zugangsdaten, internen URLs, vertraulichen Logs oder unbereinigten Screenshots einstellen. Beschreibe das Verhalten mit erfundenen Beispieldaten. Sicherheitslücken bitte über den bereits vereinbarten privaten Kontakt zum Projektteam melden.

Öffentliche Beschreibungen und Kommentare werden intern übernommen. Änderungen werden abgeglichen; gelöschte Kommentare werden als gelöscht markiert. GitHub-Benachrichtigungen und Änderungshistorien können ältere Inhalte weiterhin enthalten.
